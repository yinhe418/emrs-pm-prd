二维码中心

两类二维码,用途完全不同,不要混用。
一个医院 = 一个邀请码(不是科室级)。本页只显示顶栏当前所选医院的码,其他医院的码需先切换医院。 本院医护人员用微信扫描此码进入小程序, 扫码后进入「待分配科室」队列, 需管理员设置科室与职位后才能使用。
建议张贴位置:科室门口白板 / 护士站。
码主(医院) 二维码 科室数 扫码次数 最近扫码 待分配 状态 操作
共 0 个医院 一个医院一个码,扫码长期有效
一名医生 = 一个患者码。患者 / 家属用微信扫描此码进入小程序, 扫码后自动绑定该医生为主管医生,无需管理员操作。护士归属仍需另行指派。
只有可承担「主管医生」角色位的在岗人员才有患者码。护理岗通过主管医生指定归属,不生成患者码。
只显示本医生自己的绑定患者,互相不可见
医生 科室 职称 二维码 已绑定患者 最近绑定 状态 操作
共 0 位医生 扫码长期有效
