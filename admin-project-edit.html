任务模板(从任务库组合)
配置两个维度:
📅 日期:每天 / 出院前 N 天 / D N 天(N 由管理员输入,可任意)
👥 目标人:主管医生 / 护士 / 患者 — 可多选(如上传检查报告可同时分配给患者和主管医生)
目标人 = 角色位,不是具体人。派到某患者名下时自动解析:主管医生 = 该患者的主管医生;护士 = 该患者的主要联系护士;患者 = 患者本人。
自上而下即任务下发顺序,用 ↑ ↓ 调整。
