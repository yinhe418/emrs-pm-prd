—
枚举值由管理员手动维护,不限预设清单:点「新增枚举值」新增,点值上的 ✕ 停用。
停用 ≠ 删除:行保留、历史填报不受影响,可随时「恢复」; 该 code 槽位仍被占用,永不复用给别的概念。
code 是统计聚合键,创建后不可修改;label 是显示文案,医院可随时改,改名不影响统计分桶。
