新建项目

项目归属一个科室；项目里的任务模板从本科室的任务组件库挑组件， 每条模板配「什么时候做」和「谁来做」两个维度。

基本信息

归属科室保存后不可修改
项目的一切配置都以此为界:任务模板只能挑本科室的组件 请选择归属科室
同科室下不可重名;跨科室可以同名 项目主题 2–100 字
只作分类标签,两类项目在本模块行为一致
仅限归属科室内在职、具备医生角色位的人员。这是数据字段,不是登录身份——他本人没有本模块的后台权限 请选择主负责医生
周期天数用于校验模板「出院后第 N 天」的上限。两端都能改(PC 后台 / 小程序端) 项目周期需在 1–3650 天之间
起止日期两端都能改(PC 后台 / 小程序端)⇒ 末次写入生效,每次写入都留审计 请选择开始日期
结束日期不得早于开始日期 结束日期不得早于开始日期
选填,最多两位小数(基线 DECIMAL(10,2));仅作项目属性记录,不触发任何计费。
PC 后台与小程序端都能改这一项(改的是同一个项目属性)⇒ 末次写入生效,每次写入都留审计 定价不能为负数

0 条
配置两个维度: 日期 —— 每天 / 出院前 N 天 / 出院后第 N 天(N 以出院日为基准,由管理员输入,可任意)。顺序即任务下发顺序,用上移 / 下移调整。
目标人 —— 主管医生 / 护士 / 患者,可多选(如上传检查报告可同时分配给患者和主管医生)。
目标人 = 角色位,不是具体人。派到某患者名下时自动解析:主管医生 = 该患者的主管医生;护士 = 该患者的主要联系护士;患者 = 患者本人。
任务标记规则:每个事项有「完成」选项 + 负责人;未在指定时间完成 → 标记为待处理事项。
