# EMRS — 卒中患者全程管理软件 · 产品 Demo

> 神经内科(以 AIS / 卒中为核心)的智能病历助手 — **Q1:可点击 HTML Demo**
>
> 本仓库**只包含可点击的 HTML Demo + 静态资源**。PRD 文档未纳入版本管理,按需另行分发。

---

## 项目说明

- **产品定位**:卒中患者出院后全程管理(随访、危险因素、康复、复诊衔接)
- **目标用户**:患者 / 授权家属、责任医生、随访护士、科室主任、系统管理员
- **设计形态**:H5 + 微信小程序(本仓库为 H5 版,小程序版独立)
- **病种范围**:神经内科 / AIS(急性缺血性卒中)优先
- **当前阶段**:Q1 Demo(真实病例驱动,所有数据已脱敏)

## 本地预览

```bash
cd docs/prd/prd-stroke-p0/prototype
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/role-switch.html
```

> 入口:`role-switch.html`(角色切换器,可一键进入任一端 Demo)
> 也可直接打开 `index.html`,但 `role-switch.html` 是官方推荐起点。

## 目录结构

```
prototype/
├── role-switch.html        # 角色切换入口(从这里进)
├── index.html              # 默认首页
├── rate-popup.html         # 评分弹层(被多页引用)
├── leaderboard.html        # 排行榜
│
├── assets/
│   ├── icons-png/          # 62 个 PNG 图标(透明背景 · 柔和插画风)
│   ├── icons.svg           # SVG 图标源文件
│   ├── styles.css          # 全局样式
│   └── layout.js           # Navbar / Footer 布局脚本
│
├── patient-*.html          # 患者端  22 页
├── doctor-*.html           # 医生端  11 页
├── nurse-*.html            # 护士端   9 页
├── director-*.html         # 主任端   4 页
└── admin-*.html            # 系统端   6 页
```

## 角色一览

| 角色 | 文件前缀 | 主要场景 |
|------|---------|---------|
| 患者 | `patient-*` | 个人计划 · 任务打卡 · 紧急求助 · 评价医生护士 |
| 医生 | `doctor-*` | 我的患者 · 下发任务 · 看检查报告 · 评分 |
| 护士 | `nurse-*` | 每日清单 · 随访 · 转交 · 评分 |
| 主任 | `director-*` | 项目详情 · 月度报告 · 评级 |
| 系统 | `admin-*` | 药物清单 · 任务库 · 项目设置 |

## 数据脱敏声明 ⚠️

本仓库所有 demo 数据来自真实病例档案,**已经过脱敏处理**:

- 医院名称:已脱敏为占位
- 患者姓名:使用示例名(如"陈丙英")
- 商业药品名:已脱敏
- 主管医生 / 护士 / 主任:使用占位或脱敏

> 原始档案(含医院真实信息、商业药品名、人员姓名)**不在本仓库**,仅在内部文档系统留存。
